# flyers

**juku2expert books のチラシ置き場です。** A4・1枚にまとめた本の案内で、
印刷してそのまま配れるようにしてあります。

juku2expert books は、**中学生と、一緒に学ぶ親御さん**に向けた技術書のシリーズです。
読むだけでなく、本に載っているプログラムを**自分の指で打ち込んで(写経して)**動かし、
最後に「自分で作れた」まで行くことを目指しています。

既刊は40点を超えます。**一覧は <https://juku2expert.net/> にあります。**
ここに置いてあるのは、そのうちチラシを作った**23冊**(18枚)です。
**フロントエンドとJavaは、それぞれ全3巻を1枚にまとめて案内しています。**
並べ方は juku2expert.net と同じ分け方にしました。

### 写経で学ぶフロントエンド 全3巻 ― はじめてのWebページから、Dockerと認証まで

Webの入口は、ブラウザで開くただの一枚のページです。そこから**自分の手で打ち込んで(写経して)**
始めて、最後には人が使える**本物のWebアプリ**にたどり着く、三冊ひとつづきの道です。

**第1巻**は HTML・CSS・JavaScript。**第2巻**は TypeScript と、フレームワークの**比べ方**
(どれが正解かではなく、何を基準に選ぶか)。**第3巻**はフルスタック編で、Docker と
ログイン(認証)をつけて、ようやく他人に使ってもらえるアプリになります。

どの巻からでも読めますが、第1巻から順に進むと、作ったものがそのまま育っていきます。
三冊とも Kindle版と紙版の両方があります。

### 写経で学ぶJava 全3巻 ― 基礎とオブジェクト指向から、Web・テスト・IoTまで

Java は、銀行のシステムから Android のアプリ、大きな業務システムまで、
**いまも現場で動きつづけている言葉**です。画面に出てくるコードを
一行ずつ自分の指で打ち込んで身につける三冊です。

**第1巻**は基礎とオブジェクト指向。**第2巻**は標準ライブラリと設計 ――
動くだけでなく、あとから読める形に。**第3巻**は Web・テスト・IoT で、
作ったものを外の世界につなぎます。

第1巻から順に進むのがおすすめです。三冊とも Kindle版と紙版があります。

### 写経で学ぶGo言語 ― Goはどこが優れて、何に向いているのか?

文化祭まであと3週間。親友がPythonで作った注文サイトが、リハーサルで全校300人に固まりました。
本番は保護者も来て、千人です。

文法を順に並べた教科書ではありません。中学生たちが文化祭のたこ焼き屋を成功させようと
奮闘する**物語**の中で、**Python・C・C++と比べてGoはどこが優れていて、何に向いているのか**を
一冊かけて探ります。ゴルーチンを「職人」、チャネルを「配膳口」に見立てて、
たくさんの仕事を同時にさばくしくみを厨房の段取りそのままに理解します。

**Goが向いていないことも、正直に書いています。**

### 写経で学ぶデータサイエンス ― データサイエンティストになりたい君に。

「気がする」を、数字で「こうだった」に変える人。それがデータサイエンティストです。

去年、先輩たちは文化祭のかき氷を仕込みすぎて、たくさん捨てました。今年の模擬店係に
なったきみの目標は、完売。手がかりは、先輩が残した一冊のノートだけです。

平均と中央値、グラフのウソ、相関と因果、データの掃除、直線での予測、決定木、過学習 ――
文化祭までの**五週間の物語**で、ひとつずつ手を動かして身につけます。
全コードを実際のIPython画面(In/Out)でそのまま載せているので、画面と本を一文字ずつ
見比べられます。

### 写経で学ぶAlpine Linux ― 軽さは武器

押入れから出てきたのは、Windows XP が入ったままの小さなネットブック。
32ビットのCPUにメモリ1GB、最新のOSはもう入りません。そこに **Alpine Linux** を入れると、
その機械は一分足らずで目を覚ましました。

同級生のひとことから目標が決まります ―― **文化祭までに、ブラインドタッチ練習機を
十台作って、出品ページを書き上げる。**なぜこのOSが軽いのかを手で確かめ、練習アプリを書き、
最後は LAN起動と Ansible で同じ一台を十回作ります。

**古いパソコンが無くても大丈夫です。**付録の手順で QEMU(仮想マシン)を使えば、
第一部から第三部まで、ふだんのパソコン1台だけで写経できます。

### 写経で学ぶBlender ― Pythonで作成した3D CGをスマホで見る

黒い画面にコードを打ち込むと、映画のような3DCGが生まれる ―― その瞬間をゴールにした本です。
**マウスは使いません。**Pythonで書いた「台本」を渡すと、無料の3DCGソフト **Blender** が
撮影してくれます。あなたの役目は、光を当て、カメラを構え、動きを決める「監督」です。

**GPU(グラフィックボード)も要りません。**ふつうのパソコンのCPUだけで撮ります。
できあがった映像は、家のWi-Fiを通して家族のスマホへ。
最終章のラスボスは、夕日の中を歩く犬を、回り込みながら追いかけるカメラで撮った映像です。

ターミナル、コンテナ、Pythonの知識はゼロが前提。黒い画面の開き方から、一行ずつ進みます。

### 写経で学ぶC/C++ クラウドコストカット法

打ち込んで、動かして、**必ず測る**。同じ仕事をするプログラムでも、書き方しだいで
大きさも速さも変わります。クラウドでは、その差がそのまま毎月の請求書になって返ってきます。

物語の軸は、たった三品メニューの小さなAPIサーバー「観測小屋」。Hello World から始めて、
これをコンテナに詰め、クラウドで動かし、押し入れで眠っていた古いパソコンでも営業させます。
そのくり返しで、コンピュータの中の**メモリが「見える」**ようになります。

各章末の【キャリアの窓】では、その章の技術が求人票のどの言葉になるかを翻訳します。
**中学生と、スキルチェンジを考える親御さんが、隣り合って同じ写経をするための一冊です。**

### 写経で学ぶCOBOL ― なぜ銀行は60年前の言葉で動いているのか?

銀行の夜を、六十年前に生まれた言葉が守っています。何十万人ぶんの口座を、
一円の狂いもなく数えつづけている ―― その計算を、**JavaとRustへ引っ越させる**本です。

中学2年のハルが、銀行で四十年バッチを守ってきたじいちゃんから引き受けた約束。
合格の条件はひとつ、**月曜の朝、全員の残高が一円もずれずに並ぶこと**。

Hello から写経を始め、ピリオド一個で夜が止まる理由を確かめ、10万口座の夜間バッチを
自分で動かします。そして突合 ―― COBOL・Java・Rust の三つで同じ10万件を計算し、
一文字ずつくらべます。**Javaの第1版だけが、1件だけずれました。**

掲載したプログラムは、すべて著者が実際に動かし、出てきた結果をそのまま載せています。

### 写経で学ぶLinuxデバイスドライバ開発 ― C言語とRustで作って比べる

「いないなら、作ればいい。」おこづかいで買った赤いボタンは、光りませんでした。
専用ソフトは Windows 版しかない ―― 「じゃあ、その通訳、自分で作れないの?」
中学生ソラの、たったひとつの「なぜ?」から、旅は始まります。

山場は、カーネルを書く人が実際にやらかす**三つの事故**を、
**CとRustの両方で起こして見くらべる**ところ。Cは何ごともなかった顔で通り抜け、
Rustは同じ過ちを、動かす前にはっきり止めます。

前半は QEMU(壊してもいい実験室)だけで進められます。実機が要るのは後半です。

### 写経で学ぶRTOS ― なぜエアバッグは0.03秒で開けるのか?

ぶつかってからエアバッグがふくらみ切るまで、およそ0.03秒。その仕事をしているのは、
スマホよりずっと遅い小さなマイコンです。なぜ遅いコンピュータに命を預けられるのか ――
答えの **RTOS(リアルタイムOS)** を、文化祭のリズムマシンを作りながら学ぶ本です。

**第三部までは部品を一つも買わずに済みます。**ブラウザの中でESP32が動くシミュレータ
Wokwi だけで進み、第四部で本物のESP32(千円ほど)に引っ越します。

### 写経で学ぶADC ― スマホはどうやって人間の声を聞くのか

スマホに話しかけると答えが返ってくる。でも、スマホには耳がありません。
いったい、どうやってあなたの声を「聞いて」いるのか ―― その正体の
**ADC(アナログ-デジタル変換器)** を、自分の声を録るところから確かめていく本です。

はかる回数やビット数を**わざと減らして**、声がこもり、ロボットのようになっていくのを
耳で聞きます。後半は無料の回路シミュレータ ngspice で、ADC そのものを組み立てます。
ラスボスは「1ビットだけで自分の声を聞く」。

姉妹本『写経で学ぶDAC ― スマホはどうやって人間に話しかけるか』は、
数字を声にもどす「逆向き」の旅です。

### 写経で学ぶDAC ― スマホはどうやって人間に話しかけるか

スマホの中には、数字しかありません。では、音はどこで生まれるのか ―― 数字を音に変えている
**DAC**(デジタル-アナログ変換器)を、**自分の手で作る**本です。はんだごては使いません。

音楽ファイルの中をのぞくと、そこにあるのはただの数字の列。そこからけたを減らしていきます。
16→8→4→2→1。音楽が壊れていく瞬間を、順に聴きます。最後は、たった三行の
「まちがいを次にまわす」で、**1ビットから音楽を取り出します。**

姉妹本『写経で学ぶADC』は、**声を数字に変える**逆向きの旅です。

### 写経で学ぶPLC ― 何故PLC制御は無くならないのか?

工場の設備を動かしている **PLC(ラダー図)**と、千円のマイコン＋**RTOS** とを、
同じ機械を両方で作って見比べる本です。
「使っているPLCがもう作られていない」「マイコンで全面置き換えの提案が来た」
といった場面で、何をどう考えればよいかを、物語と手を動かす実習で追いかけます。

⚠️ **このチラシだけは、ほかと宛先がちがいます。**工場の生産技術・設備保全のご担当者と、
新人教育の担当者に向けて書いてあります。

### 次の主役を特許で先読みする

株価が動いてからニュースを読むのでは遅い。企業は、製品を発表する**何年も前**に
特許を出願します。その積み重ねは、プレスリリースよりも正直に、
**何に本気で、何を捨てているか**を記録しています。
